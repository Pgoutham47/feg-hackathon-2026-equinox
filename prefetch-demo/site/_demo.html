Finding: there is no cheap middle option between the 6.5 MB slice and the full 52 MB precache — but not because of audio. In a cold load the reel symbols complete at 5.2 s and the first audio file is not requested until 8.2 s, so no audio precedes the symbols. What is ahead of them is 24.6 MB of character and background spines. Partial precaching cannot fix "all visuals" either: with the win animations already in Cache Storage the game still does not request them until 8.9 s, because it is serially working through the rest of the bundle.
